# AutoFill-Fit Web

이력서를 한곳에서 관리하는 Next.js 14 대시보드. 백엔드는 [`../server`](../server)의 Nest.js API를 사용합니다.

## 실행

```bash
cd web
npm install
cp .env.local.example .env.local     # API 주소 확인
npm run dev                          # http://localhost:3001
```

### 포트

백엔드가 `3000`을 쓰므로 **Next는 3001에서 실행**합니다 (`next dev -p 3001`).
백엔드 쪽에는 다음 두 값이 필요합니다.

```bash
PORT=3000
CORS_ORIGINS=http://localhost:3001
```

API 주소를 바꾸려면 `.env.local`의 `NEXT_PUBLIC_API_BASE_URL`을 수정하세요.
이 값은 `NEXT_PUBLIC_` 접두사대로 **빌드 시점에 인라인**되므로, 바꾼 뒤에는 다시 빌드해야 합니다.

## 동작 메모

**완성도 점수** — 기본 인적사항 30 / 학력·경력 40 / 자격증 10 / 마스터 자소서 20, 합계 100점입니다.
숫자만 두면 근거가 보이지 않으므로 카드 하단과 사이드바에 섹션별 획득 점수를 함께 노출하고,
가장 많이 남은 섹션으로 이동하는 버튼을 둡니다. 저장 전 입력도 즉시 반영됩니다(`useWatch`).

**빈 문자열은 전송하지 않습니다** — 서버의 `@Matches` / `@IsDateString`은 `""`를 형식 위반으로 거부합니다
(`@IsOptional`은 `undefined`만 건너뜁니다). `lib/resume-form.ts`의 `omitEmpty`가 빈 값을 키째 제거하고,
학교명·회사명·문항 제목처럼 항목을 식별하는 값이 비어 있는 행은 통째로 제외합니다.

**저장 후 폼 리셋** — PATCH 응답으로 폼을 다시 채웁니다. 서버가 정규화한 값(전화번호의 하이픈 제거 등)이
화면에 반영되고 `isDirty`가 초기화되어, 저장 버튼이 정확한 상태를 가리킵니다.

**단축키** — `Cmd/Ctrl + S`로 저장합니다.

**미저장 이탈 방어** — `isDirty`일 때 `beforeunload`로 탭 닫기·새로고침을 막고,
로그아웃과 백오피스 이동에는 확인창을 띄웁니다. 자소서 1,000자를 날리는 사고를 막는 유일한 방어선입니다.

**반복 항목 접기** — 학력·경력·자격증·자소서 항목은 작성되면 접혀서 한 줄 요약만 보입니다.
항목 2개만으로 1,500px이 되던 문제를 해결한 것으로, 새 항목은 펼쳐진 채로 시작합니다.

**좁은 화면** — `lg` 미만에서는 좌측 사이드바 대신 헤더 안의 가로 탭 스트립을 씁니다.
세로 사이드바가 상단 750px을 차지해 섹션을 바꿀 때마다 최상단까지 스크롤해야 했습니다.

## 확장 프로그램 연결

대시보드 상단의 확장 카드가 세 상태를 가집니다.

| 상태 | 표시 |
| --- | --- |
| 확인 중 | "확장 프로그램을 확인하는 중" (최대 2.5초) |
| 미설치 | 설치 안내 + 압축해제 확장 로드 방법 |
| 연결됨 | 버전 · 마지막 전달 시각 · 최근 자동 채움 이력 |

**빈 이력서(0%)와 완성(100%)일 때는 완성도 카드보다 위**에 놓입니다.
신규 사용자의 첫인상이 "0%"가 아니라 "이게 뭘 해주는지"가 되고, 다 채운 사용자에게는
다음 행동이 생깁니다.

저장 시각이 전달 시각보다 최신이면 "아직 전달하지 않았습니다" 경고가 뜹니다 —
저장만으로 확장이 알게 되는 게 아니라는 사실을 숨기지 않습니다.

브리지 프로토콜은 [`../README.md`](../README.md)를 참고하세요.

### 매칭 키워드

자소서 문항마다 "매칭 키워드"를 입력할 수 있습니다. 확장이 지원서의 장문 칸에
어느 문항을 넣을지 고를 때 쓰는 신호이며, **키워드 1개만 맞아도 매칭이 성사**됩니다
(임계값 40, 키워드 45점).

제목이 서로 다른 표현으로 물어보는 문항에 씁니다 — 예를 들어 "입사 후 포부" 문항에
`3년, 목표`를 넣어 두면 "3년 뒤 자신의 모습을 적어 주세요" 같은 칸에도 붙습니다.
비워 두어도 제목·유형만으로 매칭되므로 필수는 아닙니다.

확장이 문항을 찾지 못하거나 답변이 글자수 제한을 넘으면 **그 칸은 비워 두고**
지원서 화면에서 표시로 알립니다. 잘못 채워진 자소서가 빈 자소서보다 나쁘기 때문입니다.

## 계정 화면

`/account`에서 내 데이터를 JSON으로 내려받고 탈퇴할 수 있습니다. 탈퇴 화면은
내려받기보다 **아래에** 둡니다 — 지우고 나면 되돌릴 수 없으므로 먼저 받게 하는 순서입니다.

탈퇴 시 확장에도 `CLEAR`를 보내 이 기기에 남은 개인정보를 함께 지웁니다.

`/terms`와 `/privacy`는 로그인하지 않아도 열립니다. 가입 화면의 동의 체크박스에서
새 탭으로 링크되며, 읽을 문서 없이 체크박스만 두면 동의를 받았다고 보기 어렵습니다.

## 백오피스

`/admin` 이하는 `ADMIN` 역할만 접근할 수 있습니다. 권한이 없으면 화면 구조 자체를 그리지 않고
안내만 보여주며, 대시보드 사이드바의 백오피스 링크도 관리자에게만 나타납니다.
관리자 지정 방법은 [`../server/README.md`](../server/README.md)를 참고하세요.

**개인정보는 기본이 마스킹**입니다. 상세 화면 최상단에 현재 마스킹 여부와 해제 경로를 명시하고,
원본을 보면 배너가 노란색으로 바뀌며 "감사 로그에 기록되었습니다"를 알립니다.
자기소개서 본문은 원본 열람 전까지 서버가 아예 내려보내지 않고 글자수만 표시합니다.

계정 삭제는 되돌릴 수 없으므로 확인 문구(`삭제`)를 입력해야 실행됩니다.
비활성화·권한 변경처럼 되돌릴 수 있는 작업은 모달로 막지 않습니다.

**차트** — 가입 추이와 완성도 분포는 모두 단일 계열이라 색이 정보를 나르지 않습니다.
값은 길이로만 표현하고 색은 하나(`blue-600`)로 고정했습니다. 순차 색 램프를 쓰면 밝은 단계가
배경 대비 3:1을 넘지 못해 읽히지 않습니다.

## 인증

로그인 시 받은 JWT를 `localStorage`(`autofill-fit.token`)에 저장하고, `lib/axios.ts`의 요청 인터셉터가
모든 요청에 `Authorization: Bearer` 헤더를 붙입니다. 401 응답을 받으면 토큰을 지우고 `/login`으로 보냅니다
(로그인 요청 자체의 401은 화면에서 메시지로 처리하므로 제외).
